# First-time player test — Alpha 3

This checklist is for an observer and someone who has never played THE CRAWL or read its manual. Automated walkthroughs exercise controls and outcomes; they cannot establish human comprehension. No novice human session has been run for this delivery.

Use the matching 0.3.0 host/client, a fresh browser profile, desktop mouse/keyboard, and a new private solo room. At title choose Guidance On; Settings → Reset guidance also resets progress. Reset before creating the room: the host chooses the shared teaching arrangement at room creation. Recommended repeatable seeds: `1234`, `264461152`. Start with Night Custodian, which was exercised in both browser walkthroughs. Record other backgrounds separately. Leave Inspector, Transmission Log and the external manual closed for the first ten minutes. Sound is optional; run one session with sound off.

The observer must not explain controls, symbols, rules or the relay solution. Record hesitations and questions verbatim. If the player gets stuck, record where and how long before offering help; assistance means that step did not pass independently. The time windows are observation targets, not progression gates or a claimed run duration.

| Observation | Pass condition without coaching | Result / time / confusion |
| --- | --- | --- |
| First 60 seconds | Points to their crawler; recognizes floor, wall, door and supply crate; moves using chosen input. | |
| First interaction | Approaches and opens arrival supplies; understands something was obtained. | |
| First threat | Notices exploration becoming planning; can say what 3 AP and Ready mean. | |
| Plan a round | Identifies queued movement/attack and their individual costs; predicts endpoint before Ready; can undo a mistaken step. | |
| First attack | Identifies attacker, target, hit/miss, damage and who acts next from world feedback. | |
| Shortfall | Clicking a distant enemy makes sense: the player understands why approach + attack may exceed remaining AP. | |
| Defense | Understands Guard and can intentionally combine it with a 2-AP attack. | |
| Cover | Recognizes a barricade and sees its effect on an actual target preview. | |
| Relay encounter | Notices water, machine and stationary sentry; forms a hypothesis and avoids the wet path where possible. | |
| Relay outcome | Can say what conducted, which enemy was hurt/stunned, and why the Audience reacted. No log explanation needed. | |
| Equipment | Finds Inventory after obtaining loot; can identify one practical use of an item. | |
| Inspection/input | Hover identifies the tile under the pointer; F + click pins the intended tile; Escape clears it; arrow keys move consistently afterward. | |
| After ten minutes | Explains exploration → threat → plan → Ready → outcomes in their own words; chooses a next action without observer coaching. | |

Continue beyond ten minutes for progression, floor objective, guardian danger tiles, boss devices and descent. Ask the player to predict the next enemy phase before committing. Observe whether Dodge is distinguished from leaving a boss area strike. Record whether profession/adaptation choices in the Floor 3 saferoom feel earned and understandable. These later steps are not covered by a ten-minute success claim.

Then test the expert escape hatch: Show panels → Inspector/Transmission Log, Advanced controls, Guidance Off, reload, Guidance Reset, a new run, and reconnect to the old run. Local guidance settings must persist; resetting guidance must not replace the existing saved floor. Repeat a short movement/attack/inspection session at 1280×720 and 1920×1080 after zoom and page scroll.

For each failure, classify the cause: unrecognized image, unclear intention, unclear AP cost, wrong target, unclear outcome, excessive text, hidden control, distracting feedback, or missing rule explanation. Prioritize causes that force Inspector/log use for ordinary actions. Keep the raw notes and screenshots; do not turn an observer-assisted success into an independent pass.

Acceptance remains pending until this is run with actual first-time players. Recommended next iteration: three independent sessions, compare repeated confusion, then fix the most frequent world-feedback failures before expanding content.
