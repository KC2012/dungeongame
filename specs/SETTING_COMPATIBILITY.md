# Setting compatibility and IP boundary

## Creative setting decision
The user explicitly wants a game **set in** the dungeon world of *Dungeon Crawler Carl*, rather than only a mechanically similar generic roguelike, while using NO plot or characters from the novels. This specification accordingly treats **The Concourse** as an imagined, previously unseen and entirely fictional six-floor dungeon sector, administered by an original local subroutine, The Producer. It retains the broad conceit of a televised world dungeon with spectators, advancement, sponsorship and cruel entertainment-driven rules. It is not a canon timeline or an adaptation of any particular floor from the books.

## Allowed original design choices
Original player crawlers, backgrounds, professions, body adaptations, items, monsters, room art, sponsor factions and dialogue. No named canon protagonists, chapter re-enactments, copyrighted illustrations, lifted descriptions, franchise logos, official sound recordings, book excerpts or exact book achievements. If user later provides authorized or personal references, use them only as reference and respect permission boundaries.

## Sharing note
Even fan-setting use for friends can involve copyright or trademark issues; nonprofit/private use is not an automatic exemption or authorization. Do not represent it as official. Add a respectful unofficial fan disclaimer in menu credits; avoid public marketing using the brand without permission. Before wider sharing or distribution, discuss authorization or a switch to an independent setting; code/data boundary should make this switch feasible.

## Future legal-independent variant
Keep *setting identifiers* in one data module. The Producer, Concourse, and all actual assets are original. A future version can remove the universe reference and become its own satirical televised dungeon story with no code changes to combat, progression, physics, maps, rooms, multiplayer or saves. A legal-independent variant should receive a fresh name/screen text and review before release.
